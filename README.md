# Сессионный проект PostgreSQL — вариант 4

Студент: **Лукьянчиков Валерий Геннадьевич**.

Консольное приложение Python + PostgreSQL для управления помещениями (`rooms`) и стеллажами (`racks`). Схема таблиц соответствует домашнему заданию модуля 1. Подробности установки и запуска приведены ниже.

## Установка

1. Создайте в pgAdmin базу данных `warehouse_session_v4`.
2. В этой базе выполните `sql/01_schema.sql`, при желании — `sql/02_demo_data.sql`.
3. Установите Python 3.9+ и зависимости: `python -m pip install -r requirements.txt`.
4. Скопируйте `config.example.yaml` в `config.yaml`, укажите пароль пользователя PostgreSQL и другие параметры подключения.
5. Запустите `python main.py`.

## Возможности

Добавление, редактирование, удаление и постраничный просмотр помещений и стеллажей; проверка пользовательских данных; параметризованные SQL-запросы; понятный пользователю выбор записей без ввода `id`.

Тесты: `python -m unittest discover -s tests -v`.

**Безопасность:** `config.yaml`, `.env` и виртуальные окружения исключены из Git. Не добавляйте пароль в репозиторий.
